# 驗證結果

日期：2026-11-06。教材：複利實驗室第一版。

## 自動邏輯測試

`node --test tests/*.test.mjs`：11 組通過。

- 24 題答案與 Python Decimal 40 位精度獨立計算一致，四捨五入後的答案全部被接受。
- $10,000、5%、30 年：單利息 $25,000，複利息 $43,219。
- 四組條件逐年驗證：本金 + 本金利息 + 利息的利息 = 本利和，差距 = 利息的利息。
- 13 種常見錯誤答案被正確辨認；診斷訊息不含金額，提示不含該題答案。
- 300 輪隨機抽題：每輪 10 題、不重複、五類各 2 題。
- 六個錯題個案的錯誤數字及正確答案與曲線函數一致。
- 教材檔案不含「賭」等僥倖框架用語。
